# 聊聊我眼中的大模型和 agent

我外公是个聪明人，他是远近闻名的木匠，十里八乡的不少房子都是他建的，还有不少徒弟跟着他讨生活。
但他表达过他对手机的疑惑，那时候手机刚出来不久，他觉得手机是个很神奇的东西，没有了那根电话线，怎么能打电话呢？

转眼我已经工作近二十年，技术的发展很迅猛，但如果让我评价一个让我最惊讶的技术，我会说是大模型。
对很多人而言，它是神奇和不可思议的，就像我外公当年对手机的感觉一样(当然也有人意识不到这种神奇)。
我为了更好地理解和使用它们，学过机器学习，了解过深度神经网络，了解过生成式大模型，但我的理解一直停留在表面。

生成式大模型到底有哪些能力(边界在哪里)，它们是怎么被创造出来的，它们真的有智力吗，离通用人工智能远吗？
这些问题一直困扰着我。
我觉得它们是高大上的技术，只有世界 top 10 的博士学位的高端人才才能理解和使用它们.

然而 agent 的流行，特别是 claude code，codex 等代码生成 agent 的流行，
让我对生成式大模型的理解有了脱胎换骨的认识，
我觉得 agent 是一个非常好的切入点，来理解生成式大模型的能力和边界。
我甚至想自己来实现一个 agent， 来更深入地探索它们的潜力。
最近爆火的 https://github.com/openclaw/openclaw， 似乎又隐隐开启了除了 code agent 外的另一片天地，
通用型 agent，软件形态的智能机器人，似乎呼之欲出。

对 agent 本身的理解，我也有一个渐进的过程，agent 又是什么？ 它跟提示词工程有什么区别和联系？
我自己可能看了很多碎片化的文章和资料，走了很多弯路，对应想系统和快速了解 agent 的人来说，
我推荐 b 站 up 主 "隔壁的程序员老王" 的 "AI技术" 系列的视频 [AI技术](https://space.bilibili.com/16433002/lists/5310060?type=season),
这个系列的名字取得不是很好，名字太泛泛了实际上我觉得主要是围绕 agent 的，
一共 10 多个视频，每个视频 10 分钟左右，
介绍了在使用大模型遇见了哪些问题，人们想了哪些办法解决这些问题，
生成式大模型，Prompt engineering，Tool use, MCP， RAG, Context engineering，skills 等，
最后演变成了 agent 这个概念。

![llm agent](@/assets/images/2026/llm_agent.jpg)

对程序员来说，生成式大模型和 code agent 的流行，是一个非常大挑战，也是一个机会。
为什么是挑战，因为它两的出现，会冲击和重构软件行业的工作内容和工作方式。
想象我们是汽车行业出现前的马夫，同样是运输工具，但工具的性质完全变了，工具的能力也变了，
从前掌握的马夫相关的技能，可能就没那么重要了，你需要学习汽车驾驶相关的技能，甚至是汽车维修相关的技能。
那才是朝阳行业。

我突然觉得马夫这个例子还挺合适的，用来演示生成式大模型对程序员，软件行业甚至社会的影响。

驾驶员需要会驾驶汽车，对应普通的使用者会使用大模型，提问题呀，写文章啊，生成图片和视频啊，
更加高层，不需要了解底层细节，但是本身也有很多技巧。

程序员的工作更像是围绕汽车的新的生态的开发者和建设者，围绕汽车开发很多新的工具和服务，目前对应的如 code agent 等工具， 之后一定也会有服务，
对应如旧世界的物流系统，滴滴打车等。

而大模型厂家更像是汽车制造商，他们了解汽车的底层原理，有哪些组件组成分别有哪些作用，怎么样让汽车的性能更好。

之前学习一门编程语言，你要学习它的语法，它的库，它的工具链，学习它的生态。
如今面向大模型编程，你需要学习如何和大模型进行有效的沟通，如何设计好的提示词，如何构建好上下文，
以及额外的一层考虑：哪些功能使用传统软件来实现，哪些功能使用大模型来实现，及部分由传统软件部分由大模型及如何让它们协同工作。

我要补齐后面这块，也考虑自己实现简单的 agent，打算学习和借鉴以下几个项目：
- https://github.com/badlogic/pi-mono 这个也是 openclaw 底层使用的 agent 框架
- https://github.com/HKUDS/nanobot 一个简化版本的 openclaw，功能更简单，适合入门学习
- https://github.com/PsiACE/bub

当然这里还有一个比较小的变数，
就是生成式模型它有主观能动性吗，它能自主学习进步吗，有自我意识，有情感吗？
围绕 agent 玩过一段时间之后，我觉得前两者是部分具备的，后面两条都是否定的，至少目前基于 transformer 机制的生成式大模型不太可能有自我意识的。

但尽管如此，我觉得它们的能力已经足够强大了，
新时代的程序员们，抓住时代的机遇，面向大模型编程，打造新的工具和服务，这才是我们的未来。

这里我畅想一个可能的未来，沉浸式的虚拟游戏世界，戴上 VR 头盔，进入睡眠，来到一个完全由生成式大模型驱动的虚拟世界，
里面有各种各样的智能 npc，每个 npc 有自己的故事和机遇，有自己的性格和情感，
玩家可以和他们互动，在一个虚拟的世界里面冒险，探索，社交，甚至是工作。

作为一个传统软件开发者，这个虚拟游戏世界有点太遥远了，复杂度和工作量都太高，
但借助生成式大模型和 agent 的能力，或许我们有了打造这么一个虚拟世界的能力了。
